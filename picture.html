Comment fonctionnent media et srcset ensemble ?L'attribut media décide quelle ligne charger : Le navigateur lit les lignes du haut vers le bas. Il s'arrête sur la première balise dont la condition media est vraie par rapport à la taille actuelle de l'écran.Le paramètre srcset décide quelle densité choisir : Une fois la bonne source sélectionnée, le navigateur regarde les options de srcset. La notation 2x (ou 3x) permet de cibler les écrans Retina ou haute densité. Si l'utilisateur possède un écran classique, il télécharge image-medium.jpg. S'il a un écran haute densité, il télécharge automatiquement image-medium-2x.jpg pour un rendu plus net.La balise est obligatoire : Elle sert de solution de secours (fallback) pour les anciens navigateurs et affiche l'image par défaut sur les smartphones de moins de 768 px.
