Pour créer un carousel moderne en CSS avec support du défilement (scroll) et du glisser-déposer (drag), la méthode la plus performante consiste à utiliser scroll-snap combiné avec une touche de JavaScript.
Aujourd'hui, le "drag" natif en pur CSS n'existe pas, mais en ajoutant seulement quelques lignes de JavaScript, vous obtenez un effet fluide et parfaitement optimisé pour le mobile et le bureau.
Voici le code complet, propre et prêt à l'emploi.

💻 Le Code Complet

html
<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <title>Carousel Moderne CSS/JS</title>
  <style>
    /* Configuration du conteneur principal */
    .carousel-container {
      --gap: 16px;
      display: flex;
      gap: var(--gap);
      overflow-x: auto;
      scroll-snap-type: x mandatory;
      padding: 20px;
      scrollbar-width: none; /* Masque la barre sur Firefox */
      cursor: grab;
      user-select: none; /* Empêche la sélection de texte pendant le drag */
      scroll-behavior: smooth;
    }

    /* Masque la barre sur Chrome, Safari et Edge */
    .carousel-container::-webkit-scrollbar {
      display: none;
    }

    /* Changement de curseur lors du drag */
    .carousel-container.active {
      cursor: grabbing;
      scroll-behavior: auto; /* Désactive le smooth scroll pendant le drag pour éviter les conflits */
    }

    /* Style des cartes (items) du carousel */
    .carousel-item {
      flex: 0 0 calc(33.333% - (var(--gap) * 2 / 3)); /* 3 éléments par vue */
      min-width: 250px; /* Sécurité pour le mobile */
      scroll-snap-align: start;
      background: #3498db;
      color: white;
      border-radius: 12px;
      padding: 40px 20px;
      box-sizing: border-box;
      text-align: center;
      font-family: sans-serif;
      font-size: 1.5rem;
      box-shadow: 0 4px 15px rgba(0,0,0,0.1);
    }
    
    /* Alternance de couleur pour l'esthétique */
    .carousel-item:nth-child(even) {
      background: #2ecc71;
    }
  </style>
</head>
<body>

  <div class="carousel-container" id="carousel">
    <div class="carousel-item">Item 1</div>
    <div class="carousel-item">Item 2</div>
    <div class="carousel-item">Item 3</div>
    <div class="carousel-item">Item 4</div>
    <div class="carousel-item">Item 5</div>
    <div class="carousel-item">Item 6</div>
  </div>

  <script>
    const carousel = document.getElementById('carousel');
    let isDown = false;
    let startX;
    let scrollLeft;

    carousel.addEventListener('mousedown', (e) => {
      isDown = true;
      carousel.classList.add('active');
      startX = e.pageX - carousel.offsetLeft;
      scrollLeft = carousel.scrollLeft;
    });

    carousel.addEventListener('mouseleave', () => {
      isDown = false;
      carousel.classList.remove('active');
    });

    carousel.addEventListener('mouseup', () => {
      isDown = false;
      carousel.classList.remove('active');
    });

    carousel.addEventListener('mousemove', (e) => {
      if (!isDown) return;
      e.preventDefault();
      const x = e.pageX - carousel.offsetLeft;
      const walk = (x - startX) * 1.5; // Ajustez le multiplicateur pour la vitesse du drag
      carousel.scrollLeft = scrollLeft - walk;
    });
  </script>

</body>
</html>
Utilisez le code avec précaution.

🛠️ Comment ça fonctionne ?

• scroll-snap-type: x mandatory : Dit au CSS d'aligner automatiquement les éléments sur l'axe horizontal dès que l'utilisateur arrête de scroller ou de draguer.
• scroll-snap-align: start : Indique que le bord gauche de chaque carte doit se caler parfaitement sur le bord gauche du conteneur.
• scrollbar-width: none : Masque la barre de défilement pour un effet "application mobile" épuré.
• Le JavaScript : Calcule l'écart entre le point de clic initial (startX) et la position actuelle de la souris pour déplacer dynamiquement le scrollLeft du conteneur.

💡 Avantages de cette méthode

• Ultra-rapide : Utilise le moteur de rendu natif du navigateur pour le défilement.
• Responsive natif : Fonctionne au doigt sur mobile (via le swipe natif) et à la souris sur PC (via le script de drag).
• Léger : Pas besoin de charger une lourde bibliothèque tierce comme Swiper.js.

<body>

  <div class="carousel-wrapper">
    <!-- Boutons de navigation -->
    <button class="nav-btn prev-btn" id="prevBtn">❮</button>

    <!-- Carousel -->
    <div class="carousel-container" id="carousel">

  <script>
    const carousel = document.getElementById('carousel');
    const prevBtn = document.getElementById('prevBtn');
    const nextBtn = document.getElementById('nextBtn');

    /* --- LOGIQUE DES BOUTONS --- */
    
    // Calcule la largeur d'un item + le gap pour scroller exactement de la bonne distance
    function getScrollAmount() {
      const item = carousel.querySelector('.carousel-item');
      const gap = parseFloat(getComputedStyle(carousel).gap) || 0;
      return item.offsetWidth + gap;
    }

    nextBtn.addEventListener('click', () => {
      carousel.scrollLeft += getScrollAmount();
    });

    prevBtn.addEventListener('click', () => {
      carousel.scrollLeft -= getScrollAmount();
    });


    /* --- LOGIQUE DU DRAG (SOURIS) --- */
    let isDown = false;
    let startX;
    let scrollLeft;

    carousel.addEventListener('mousedown', (e) => {
      isDown = true;
      carousel.classList.add('active');
      startX = e.pageX - carousel.offsetLeft;
      scrollLeft = carousel.scrollLeft;
    });

    carousel.addEventListener('mouseleave', () => {
      isDown = false;
      carousel.classList.remove('active');
    });

    carousel.addEventListener('mouseup', () => {
      isDown = false;
      carousel.classList.remove('active');
    });

    carousel.addEventListener('mousemove', (e) => {
      if (!isDown) return;
      e.preventDefault();
      const x = e.pageX - carousel.offsetLeft;
      const walk = (x - startX) * 1.5;
      carousel.scrollLeft = scrollLeft - walk;
    });
  </script>

</body>

🛠️ Ce qui a changé :

• Calcul dynamique (getScrollAmount) : Au clic, le script calcule précisément la largeur d'une carte (y compris l'espace gap). Cela garantit que le bouton défile pile d'un élément à la fois, peu importe la taille de l'écran.
• scroll-behavior: auto pendant le drag : Dans le CSS, lorsque le carousel est en mode active (pendant le drag), le comportement fluide est coupé temporairement. Cela évite que le scroll natif "lutte" contre la souris pendant le glissement.
Souhaitez-vous maintenant que l'on configure les Media Queries pour que le carousel n'affiche qu'un seul élément sur mobile et passe à trois sur ordinateur ?
