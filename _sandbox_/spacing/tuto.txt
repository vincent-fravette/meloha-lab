En 2026, l'espacement moderne en CSS repose sur des unités relatives (rem, em), des propriétés logiques (margin-block, padding-inline) et le contrôle de l'espacement via le parent avec gap. On évite au maximum les pixels fixes (px) pour garantir une accessibilité parfaite.
Le standard de fait repose sur un système à échelle (souvent basé sur des multiples de 4px ou 8px), appliqué grâce aux variables CSS modernes.

1. Titres (<h1> à <h6>) et Paragraphes (<p>)

L'approche moderne consiste à utiliser les propriétés logiques de marge (haut et bas) et à l'exprimer en em afin que l'espacement reste proportionnel à la taille de la police.
css
/* Définition globale du rythme vertical pour le texte */
:where(h1, h2, h3, h4, h5, h6, p) {
  margin-block-start: 0; /* Évite les surprises en haut de conteneur */
}

h1 {
  font-size: 2.5rem;
  margin-block-end: 0.5em; /* Espace proportionnel à la taille du titre */
  line-height: 1.1;        /* Plus le texte est grand, plus l'interligne est serré */
}

h2 {
  font-size: 2rem;
  margin-block-end: 0.6em;
  line-height: 1.2;
}

h3 {
  font-size: 1.5rem;
  margin-block-end: 0.7em;
  line-height: 1.3;
}

p {
  font-size: 1rem;         /* Équivaut généralement à 16px par défaut */
  margin-block-end: 1.25rem; /* Un écart d'environ 20px pour une bonne lisibilité */
  line-height: 1.6;        /* Interligne standard pour le corps de texte */
}
Utilisez le code avec précaution.

2. Sections (<section>) et Grands Blocs

Pour les structures globales, l'espacement se fait via le padding interne de la section. Le standard actuel utilise des unités fluides (comme clamp()) ou de grandes valeurs en rem pour aérer les designs modernes.
css
section {
  /* Espacement interne vertical (haut/bas) et horizontal (gauche/droite) */
  padding-block: clamp(3rem, 8vw, 6rem); /* S'adapte de 48px à 96px selon l'écran */
  padding-inline: 1.5rem;                /* Sécurité sur mobile */
}

/* Espacement entre plusieurs sections adjacentes s'il n'y a pas de padding */
section + section {
  margin-block-start: 4rem; /* 64px */
}
Utilisez le code avec précaution.

3. Modèle d'Espacement Global (Le standard de l'industrie)

Plutôt que d'appliquer des marges individuelles partout, la tendance en 2026 est de gérer l'espace global depuis le conteneur via Flexbox ou Grid en exploitant la propriété gap.
Voici la configuration type d'un projet moderne structuré avec des variables CSS :
css
:root {
  /* Système d'échelle d'espacement standard */
  --space-xs: 0.5rem;  /* 8px */
  --space-sm: 0.75rem; /* 12px */
  --space-md: 1rem;    /* 16px */
  --space-lg: 1.5rem;  /* 24px */
  --space-xl: 2rem;    /* 32px */
  --space-2xl: 4rem;   /* 64px */
}

/* Conteneur de page ou de formulaire (Flux vertical automatique) */
.flow-container {
  display: flex;
  flex-direction: column;
  gap: var(--space-lg); /* Tous les éléments enfants seront espacés de 24px */
}

/* Exemple pour un composant de carte (Card) */
.card {
  padding: var(--space-xl);
  display: grid;
  gap: var(--space-sm); /* Espacement serré entre le titre, le texte et le bouton */
}
Utilisez le code avec précaution.

Synthèse des règles d'or en 2026 :

• Propriétés logiques : Utilisez margin-block à la place de margin-top/bottom, et padding-inline à la place de padding-left/right.
• Utilisation de gap : Priorisez gap dans un parent display: flex ou grid pour éviter les bugs de fusion des marges (margin-collapse).
• Pas de px pour le texte : Restez sur du rem (pour la cohérence globale de l'interface) ou du em (pour que l'espace s'ajuste si vous modifiez la taille de la police de l'élément).

Pour un site vitrine moderne en CSS brut, l'objectif principal est de créer un rythme vertical aéré, élégant et parfaitement fluide entre le mobile et le bureau sans multiplier les media queries.
Voici le blueprint d'espacement standard à copier-coller directement dans votre fichier style.css :
css
/* ==========================================================================
   1. VARIABLES & SYSTÈME D'ÉCHELLE (Dédié Site Vitrine)
   ========================================================================== */
:root {
  /* Échelle de base fluide (S'adapte automatiquement à l'écran) */
  --space-3xs: 0.25rem; /* 4px */
  --space-2xs: 0.5rem;  /* 8px */
  --space-xs:  0.75rem; /* 12px */
  --space-sm:  1rem;    /* 16px */
  --space-md:  1.5rem;  /* 24px */
  --space-lg:  2rem;    /* 32px */
  --space-xl:  3rem;    /* 48px */
  
  /* Marges géantes pour séparer les sections du site vitrine */
  --space-section: clamp(4rem, 8vw, 8rem); /* Fluide de 64px à 128px */
  
  /* Largeur max du contenu de la vitrine */
  --max-width: 1200px;
}

/* ==========================================================================
   2. MISE EN PAGE DES SECTIONS
   ========================================================================== */
section {
  /* Le padding-block crée l'espace interne (haut/bas) de la section */
  padding-block: var(--space-section);
  /* Sécurité sur les côtés pour le mobile */
  padding-inline: var(--space-md); 
}

/* Conteneur pour centrer le contenu sans toucher aux paddings de la section */
.container {
  max-width: var(--max-width);
  margin-inline: auto;
}

/* ==========================================================================
   3. TYPOGRAPHIE & RYTHME VERTICAL (The "Flow" Pattern)
   ========================================================================== */

/* Gestion globale : on supprime les marges par défaut pour tout contrôler */
:where(h1, h2, h3, h4, p, ul, ol) {
  margin-block: 0;
}

/* 
   Le sélecteur "Hibou" (+ + +) applique un espacement uniquement EN AMONT 
   d'un élément s'il suit un autre élément. Fini les marges qui dépassent !
*/
.stack > * + * {
  margin-block-start: var(--space-md); /* Espacement par défaut entre deux blocs (24px) */
}

/* Ajustements fins selon la nature des éléments textuels */
h1 {
  font-size: clamp(2.5rem, 5vw, 4rem);
  line-height: 1.1;
  font-weight: 800;
  /* Un h1 a besoin de respirer avec le texte qui le suit */
  margin-block-end: var(--space-md); 
}

h2 {
  font-size: clamp(1.8rem, 4vw, 2.75rem);
  line-height: 1.2;
  /* Un sous-titre doit être plus proche de son paragraphe que du bloc précédent */
  margin-block-start: var(--space-xl) !important; 
  margin-block-end: var(--space-sm);
}

h3 {
  font-size: 1.5rem;
  line-height: 1.3;
  margin-block-start: var(--space-lg) !important;
  margin-block-end: var(--space-xs);
}

p {
  font-size: 1.125rem; /* 18px pour une lecture ultra-confortable sur site vitrine */
  line-height: 1.7;
  color: #374151; /* Code couleur doux pour les yeux */
}

/* Espacement spécifique entre deux paragraphes consécutifs */
p + p {
  margin-block-start: var(--space-sm);
}
Utilisez le code avec précaution.

Comment l'utiliser proprement dans votre HTML ?

Pour que ce système en CSS brut fonctionne de manière magique, structurez votre HTML en utilisant la classe .stack (qui gère l'espacement automatique de ses enfants directs) et .container :
html
<section>
  <div class="container stack">
    <h1>Le titre principal de votre vitrine</h1>
    <p>Introduction accrocheuse. Tous les espaces ici sont gérés par la classe ".stack" de manière automatique en CSS, sans créer de conflits de marges.</p>
    
    <h2>Notre expertise</h2>
    <p>Premier paragraphe d'explication textuelle.</p>
    <p>Deuxième paragraphe, légèrement plus proche du premier grâce à la règle "p + p".</p>
  </div>
</section>

<section style="background-color: #f9fafb;">
  <div class="container stack">
    <h2>Section suivante</h2>
    <p>L'espace entre cette section et la précédente est parfaitement fluide grâce à "clamp()" appliqué sur le padding de la section.</p>
  </div>
</section>
Utilisez le code avec précaution.
